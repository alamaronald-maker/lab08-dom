# Laboratorio 08 – DOM, eventos y objetos

## Descripción

Este proyecto corresponde al Laboratorio 08 del curso de Diseño Avanzado de Interfaces. Tiene como objetivo practicar JavaScript mediante la manipulación del DOM, el manejo de eventos, la validación de formularios y el uso de clases y objetos.

Además, incluye una aplicación web de gestión financiera personal, desarrollada con HTML, CSS y JavaScript, con autenticación y almacenamiento de información mediante Supabase.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- Git y GitHub
- GitHub Pages

## Ejercicios desarrollados

### Ejercicio 2: DOM

- Modificación del contenido del título.
- Cambio de color mediante JavaScript.
- Aplicación de una clase CSS.
- Creación y agregado de elementos a una lista.

### Ejercicio 3: Eventos

- Implementación de botones para sumar y reiniciar un contador.
- Uso de `addEventListener`.
- Pruebas con los eventos `click`, `dblclick` y `mouseover`.
- Exploración del objeto evento en la consola.

### Ejercicio 4: Input y submit

- Captura del nombre ingresado.
- Actualización dinámica de un saludo.
- Validación del correo electrónico.
- Uso de `preventDefault()` para evitar la recarga de la página.

### Ejercicio 5: Clases y objetos

- Creación de objetos mediante una clase `Producto`.
- Registro y visualización de productos.
- Aplicación de descuentos mediante métodos.

## Proyecto de gestión financiera – Carpeta tarea

Se desarrolló una aplicación web para gestionar las finanzas personales. Sus funcionalidades principales son:

- Registro y administración de fuentes de ingresos.
- Registro, edición y eliminación de ingresos y gastos.
- Visualización del historial de movimientos.
- Consulta de resúmenes diarios y mensuales.
- Autenticación de usuarios mediante Supabase.
- Protección de los registros financieros mediante políticas RLS.
- Panel de administración para consultar los usuarios registrados.
- Cierre automático de sesión después de 15 minutos de inactividad.

**Aplicación publicada:**

https://alamaronald-maker.github.io/lab08-dom/tarea/

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta `lab08-dom` en Visual Studio Code.
3. Para ejecutar los ejercicios iniciales, abrir el archivo `index.html` de la raíz con un navegador.
4. Para ejecutar la aplicación financiera, abrir `tarea/index.html` con Live Server.
5. Interactuar con las funcionalidades de cada proyecto.
